# 企业知识库搭建指南

## 一、准备工作

### 1.1 文档梳理
在搭建企业知识库前，建议先进行文档梳理：

1. **产品文档**：产品介绍、功能说明、用户手册
2. **技术文档**：API 文档、架构说明、运维指南
3. **管理文档**：流程规范、制度文件、会议纪要
4. **数据报表**：销售数据、运营数据、分析报告

### 1.2 文档格式
系统支持以下格式：
- **Markdown (.md)**：首选格式，保留格式和排版
- **TXT (.txt)**：纯文本，通用性最强
- **PDF (.pdf)**：常见格式，自动提取文字
- **DOCX (.docx)**：Word 文档，自动提取文字
- **CSV (.csv)**：表格数据，自动转为文本

### 1.3 最佳实践

#### 文档质量
- 每个文件聚焦一个主题
- 使用清晰的标题层级
- 保持内容简洁准确
- 避免过多格式干扰

#### 文档大小
- 单文件建议不超过 10MB
- 超过 10000 字的文档建议拆分
- 多个小文件比一个大文件效果更好

## 二、上传流程

1. 使用管理员账号登录系统
2. 进入「管理后台 → 文档管理」
3. 拖拽或选择文件上传
4. 系统自动完成：解析 → 分块 → 向量化
5. 上传完成后即可在对话中提问

## 三、验证方法

上传后可通过以下问题验证：

**产品类文档：**
- "我们的产品有哪些核心功能？"
- "产品解决了什么业务痛点？"

**技术类文档：**
- "系统的技术架构是怎样的？"
- "支持哪些 API 接口？"

**数据类文档：**
- "去年的销售额是多少？"
- "哪个产品线的增长率最高？"
