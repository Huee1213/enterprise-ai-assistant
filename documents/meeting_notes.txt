企业 AI 知识助手项目 —— 2026年7月 项目评审会议纪要

日期：2026-07-15
地点：线上会议（腾讯会议）
参会人员：张三（产品经理）、李四（技术总监）、王五（开发负责人）

一、项目进度回顾
-------------
1. 已完成功能：
   - JWT 双角色认证（管理员/员工）
   - 文档上传与 RAG 检索
   - LangGraph Agent 多工具调用
   - 长短期记忆系统
   - 流式实时对话

2. 进行中的工作：
   - 文档预览优化（原始内容 + 文本块展示）
   - 对话消息批量管理
   - 系统性能优化

二、问题与风险
-----------
1. 免费 LLM API 频率限制问题
   方案：切换到付费 API 或部署本地模型

2. 向量库 Milvus 在低配机器上性能一般
   方案：考虑 Qdrant 作为备选方案

3. 前端首次加载较慢
   方案：做代码分割和懒加载优化

三、下一阶段计划
-----------
1. 增加文档批量导入功能
2. 支持知识库分类和搜索
3. 增加数据统计仪表盘
4. 完善单元测试和集成测试
